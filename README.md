# 2D Platformer Game Using Unity

This repository contains the development of a 2D platformer game built using **Unity** and **C#**. The project demonstrates the implementation of core platformer mechanics, player movement, physics-based interactions, enemy behavior, and user interface systems while following modern game development practices.

---

# About

The purpose of this repository is to showcase the development of a classic side-scrolling platformer game using Unity. It serves as a practical learning project for implementing essential gameplay mechanics, level design, animation, and game logic.

This repository also acts as a portfolio project, demonstrating proficiency in Unity game development and object-oriented programming using C#.

# Getting Started

## Prerequisites

* Unity Hub
* Appropriate Unity Editor version (refer to the project settings)
* Visual Studio 2022 or Visual Studio Code

## Installation

Clone the repository:

```bash
git clone https://github.com/DURKESH-KUMAR/2D-Platformer-Game-Using-Unity.git
```

Open Unity Hub, add the cloned project, and open it using the required Unity Editor version.
